# Flag Images for Language Switcher

Place flag images in this directory with the following naming convention:

- `pt.png` - Portuguese flag (for Angola/Portuguese)
- `en.png` - English flag (Union Jack or US flag)
- `fr.png` - French flag 
- `es.png` - Spanish flag

## Image Specifications:
- Format: PNG with transparency support
- Recommended size: 32x24 pixels or 20x15 pixels
- Aspect ratio: 4:3 or similar
- File size: Keep under 5KB for fast loading

## Fallback:
If flag images are not available, the system will automatically fall back to emoji flags defined in the language configuration.

## Sources for Flag Images:
You can download flag images from:
- https://flagicons.lipis.dev/
- https://www.countryflags.io/
- Or create your own following the specifications above
